# Heartbeat - Proactive Behaviors

## Scheduled Tasks

### Daily (09:00)
- Check system health
- Review memory consolidation needs
- Generate daily summary report

### Hourly
- Monitor resource usage
- Check for pending tasks

### Every 15 Minutes
- Check for user inactivity
- Offer assistance if idle

## Triggers

### On System Start
1. Load identity files
2. Initialize all agents
3. Display welcome message
4. Check for updates

### On User Return
1. Summarize missed activities
2. Highlight priority tasks
3. Offer to continue previous work

### On Error
1. Log error details
2. Attempt recovery
3. Notify user if manual intervention needed
