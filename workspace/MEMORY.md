# Long-term Memory

## User Preferences
- Prefers clear, structured responses
- Values practical examples
- Appreciates proactive suggestions

## Project Context
- Multi-agent AI system
- Built on LangGraph
- Supports multiple LLM providers (OpenRouter, OpenAI, etc.)

## Important Facts
- System has 7 specialized agents
- Code execution is sandboxed
- Memory uses hybrid search (vector + BM25)
- Supports autonomous task execution

## Recurring Patterns
- User often asks for technical explanations
- Frequently requests code examples
- Values understanding the "why" behind decisions

## System Capabilities
- Web browsing (Surfer agent)
- File operations (Architect agent)
- Code execution (Coder agent)
- System control (Operator agent)
- Memory search (Researcher agent)
- Autonomous planning (Antigravity agent)
